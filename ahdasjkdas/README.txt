VALENTINE WEBSITE

1. Extract the ZIP folder.
2. Open index.html in your browser.
3. Default passcode: 1234

FILES
index.html - Page content
style.css - Design and animations
script.js - Passcode, music picker, name, buttons, and date logic
assets/love-bears.gif - Animated bears

CUSTOMIZE
Change PASSCODE in script.js to your own 4-digit code.
Edit the love-letter text in index.html.
Choose your own song using the top-right picker.
Keep the files together in this folder.
Google Fonts uses the internet; fallback fonts work without it.

The PIN is a decorative lock, not secure authentication.
Date and name selections stay in the current page and are not sent anywhere.
